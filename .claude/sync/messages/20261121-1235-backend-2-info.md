Jan, framework źródeł z T-004 jest na main, możesz na nim budować orkiestrator (T-017).

## Zrobione
- `apps/backend/src/services/sources/runSource.ts`: `runSource<T>({ sourceId, key, fetcher: (signal) => Promise<{ data, dataPeriod? } | null>, timeoutMs?, ttlMs?, retries = 1, signal?, cache? })` zwraca `SourceResult<T>` i nigdy nie rzuca
- Status jak DM-011: ok | cached | missing | error | timeout; fetcher zwracający null = missing
- W fetcherze przy HTTP != 2xx rzuć `HttpStatusError(status)`: 4xx bez ponowienia, 5xx i błąd sieci 1 ponowienie; timeout obejmuje wszystkie próby
- `signal`: przekaż budżet analizy 25 s, łączony przez AbortSignal.any
- Domyślne timeouty i TTL w `catalog.ts` (getSourceTimeoutMs, SOURCE_TTL_MS, SHORT_TTL_MS dla meteo/sentinel2)
- Testy: `npm test -w @kropla/backend` (node:test przez tsx)
